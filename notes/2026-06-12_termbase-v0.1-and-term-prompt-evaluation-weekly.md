# 2026-06-12 术语库 V0.1 与术语约束翻译实验周报

## 1. 本周工作概览

本周围绕法律法规翻译项目中的**术语库基础能力建设**与**术语约束翻译效果验证**开展工作，目标是将术语库能力从“静态术语表”推进到可运行的最小闭环，并接入现有 Qwen-Max 翻译 POC。

本周已完成术语库基础模块 V0.1 的主要实验链路，包括：

- 术语表结构设计与汽车法规术语整理；

- Qwen-Max baseline 与 term-prompt 两轮翻译实验；
- XCOMET-XXL-QE 自动质量评估；
- 按语种统计 baseline 与 term-prompt 的质量差异；
- 术语覆盖率与术语命中样本质量分析；
- 翻译失败样本统计与问题归因；
- 输出汇总 Excel 报告，形成阶段性实验结论。

本周工作的核心结论是：**术语 Prompt 对部分语种有正向提升，但整体效果并不稳定；术语命中样本往往是更复杂、更专业的法规句子，因此不能只用 XCOMET-QE 均值判断术语方案是否有效，还需要结合术语一致率、术语覆盖率和人工案例分析。**

本周实验对比两种翻译设置：

| 实验组 | 模型 | 说明 |

- 各语种 baseline 平均分；
- 各语种 term-prompt 平均分；
- term-prompt 相对 baseline 的均值变化；
- 术语覆盖率；
- 术语命中样本与非术语命中样本的质量差异；

## 4. Baseline vs Term-Prompt 评估结果

### 4.1 总体对比结果

本轮实验中，术语 Prompt 对不同语种的影响存在明显差异。整体来看：

- **明显提升**：德语、瑞典语；
- **基本持平**：英语、俄语、泰语、阿拉伯语、葡萄牙语、越南语、挪威语；
- **出现下降**：法语、西班牙语、马来语、印尼语、荷兰语、意大利语。

### 4.2 初步观察

本轮对比显示，术语 Prompt 并没有在所有语种上带来稳定提升。其影响更接近“有条件有效”：

- 对**德语**和**瑞典语**，术语 Prompt 带来了可观察的平均分提升；
- 对**英语、俄语、葡萄牙语**等语种，整体变化较小，可视为基本持平；
- 对**法语、马来语、印尼语、荷兰语、意大利语**等语种，term-prompt 平均分下降，需要进一步排查 Prompt 约束、术语匹配质量和术语译法适配性。

需要注意的是，XCOMET-QE 更偏向整体语义质量和流畅度评估，并不完全等价于术语一致率。因此，术语 Prompt 导致 XCOMET 下降，并不必然说明术语方案无效，也可能说明模型在满足术语要求时牺牲了局部表达自然度。

### 6.2 分析结论

多数语种中，术语命中样本的 XCOMET-QE 均值低于非术语样本。初步判断原因包括：

1. **术语命中样本本身更难**  
   命中术语的句子通常包含法规条款、技术名词、长句结构、编号引用和复杂从句，因此天然难度更高。

2. **术语 Prompt 可能影响表达流畅性**  
   模型为了满足指定译法，可能牺牲了局部语序、搭配和中文表达自然度。

3. **术语库译法可能未充分上下文化**  
   部分术语存在多义性，同一个源词在不同法规上下文中可能需要不同中文译法。

4. **术语匹配存在误报风险**  
   V0.1 阶段以 exact match 为主，未充分处理词形变化、短语边界、缩写歧义和上下文消歧。

5. **XCOMET-QE 与术语一致性目标不完全一致**  
   XCOMET-QE 更关注整体翻译质量，不会专门奖励“使用指定术语译法”。因此后续必须同步引入术语一致率指标。

因此，本轮结果不能简单解读为“术语库降低了质量”，更准确的结论是：**术语命中样本暴露了当前系统在复杂法规术语场景下的质量瓶颈。**

## 7. 翻译失败样本分析

### 7.1 失败样本统计

本轮 term-prompt 翻译中存在少量失败样本，主要表现为空译文：

| 语言 | Failed Rows | Reason |
|---|---:|---|
| 德语 | 5 | missing_or_empty_mt_text |
| 瑞典语 | 4 | missing_or_empty_mt_text |
| 印尼语 | 1 | missing_or_empty_mt_text |

总计失败样本 10 条。

### 7.2 失败原因初步判断

失败原因主要为：

`missing_or_empty_mt_text`

结合失败样本内容，可能原因包括：

- 源文格式异常，例如德语中存在大量字符间空格；
- 句子较长，包含多层编号和法规引用；
- Prompt 中术语表和原文叠加后上下文变长；
- 模型接口返回空内容或被异常截断；
- 个别样本文本质量较差，需要预清洗。

### 7.3 后续处理建议

后续建议增加：

- 空译文自动重试机制；
- 对异常空格、断词、OCR 噪声进行预处理；
- 对长句进行更细粒度切分；
- 对失败样本单独保存并回灌测试集；
- 翻译接口增加错误码、响应日志和重试次数记录。

## 9. 问题与风险

### 9.1 术语库覆盖不均衡

当前术语库对不同语种覆盖率差异明显。法语、俄语、荷兰语、德语覆盖率偏低，影响 term-prompt 实验结论的可靠性。

### 9.2 Prompt 约束粒度偏粗

当前 Prompt 要求“严格使用术语表中的指定译法”，但没有区分：

- 高优先级术语；
- 低优先级术语；
- 可替换译法；
- 上下文相关术语；
- 缩写和全称；
- 多义术语。

这可能导致模型在部分句子中生硬套用术语。

### 9.3 XCOMET-QE 指标不完全适配术语目标

XCOMET-QE 可以评估整体质量，但不能直接替代术语一致率。后续需要形成双指标评估：

`综合判断 = XCOMET-QE + 术语一致率 + 人工抽检`

### 9.4 失败样本仍需工程处理

term-prompt 版本出现 10 条空译文，需要增加接口重试、预清洗和异常样本隔离机制。

下周建议围绕“术语库质量提升”和“术语约束策略优化”继续推进。

- 对低覆盖语种进行术语补齐；

- 清理过泛术语和高误报术语。

### 10.2 术语一致率报告完善

完善 `check_term_consistency.py`，输出：

- total_term_hits；
- correct_term_hits；
- wrong_term_hits；
- term_consistency_rate；
- error_type；
- source_term；
- expected_target_term；
- actual_translation；

目标是形成面向 RFP 的核心指标：

`术语一致率 = 正确使用指定译法的术语数 / 源文命中术语总数`

### 10.3 Prompt 策略优化

尝试不同术语注入方式：

1. 只注入高优先级术语；
2. 按 domain 筛选术语；
3. 将术语表放在 Prompt 后部或前部进行对比；
4. 对术语数量较多的句子限制注入上限；
5. 对多义术语增加上下文说明；
6. 在译后增加术语校验与轻量后处理。

### 10.4 低分样本人工归因

重点抽样分析：

- 法语；
- 瑞典语；
- 德语；
- 印尼语；
- 越南语。

分析维度包括：

- 是否术语误匹配；
- 是否指定译法不合适；
- 是否 Prompt 造成表达生硬；
- 是否源文存在 OCR 或格式异常；
- 是否 XCOMET-QE 对法规术语不敏感。

### 10.5 翻译失败样本修复

- 对空译文样本增加自动重试；
- 对字符间空格样本进行清洗；
- 对超长句进行分句；
- 保留失败日志与原始响应；
- 将失败样本加入回归测试集。

本周完成了术语库基础模块 V0.1 的核心闭环建设，并完成了 Qwen-Max baseline 与 term-prompt 的多语种对比实验。

实验结果表明：

1. 术语 Prompt 对德语、瑞典语有一定提升；
2. 对英语、俄语、葡萄牙语等语种整体影响较小；
3. 对法语、马来语、印尼语、荷兰语、意大利语等语种出现不同程度下降；
4. 术语覆盖率在不同语种间差异明显；
5. 命中术语的样本通常更复杂，不能仅凭 XCOMET-QE 判断术语方案优劣；
6. 后续需要将术语一致率纳入主评估指标，并结合人工抽检进行判断。

总体来看，本周已实现从“术语库准备”到“术语注入翻译”再到“自动评估汇总”的最小可运行闭环，为后续术语库扩充、术语强约束、译后修正和法规翻译质量提升打下了基础。
