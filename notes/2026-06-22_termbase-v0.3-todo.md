\## 4. Problem Types



| Problem Type | Handling Method |

|---|---|

| `missing` | Check injection failure, unnatural translation, or prompt ignoring; add alias or adjust prompt if needed |

| `partial\_match` | Check whether multi-word term is too long; add alias or split term if needed |

| `wrong\_translation` | Review current `target\_term`; correct target translation if needed |

| `bad\_target\_term` | Add to target-term correction list |

| `prompt\_rigid` | Lower priority or adjust note to avoid forced injection |

| `broad term` | Downgrade to low, exclude from core high terms, or mark as review |

| `statistical\_false\_positive` | Add acceptable translation to alias or adjust matching rule |

\## 9. Suggested Review Workflow



1\. Review `termbase\_v0.3\_candidate\_updates.csv`.

2\. Confirm each candidate's `problem\_type`.

3\. Fill `suggested\_target\_term` where target term needs correction.

4\. Fill `suggested\_alias` where alias should be added.

5\. Confirm `suggested\_priority`.

6\. Confirm `suggested\_status`.

7\. Add final reviewer decision in `decision\_status`.

8\. Merge accepted changes into Termbase V0.3 only after review.
