# 标准法规翻译子模块需求说明

## 1. 项目定位

本仓库服务于广汽标准法规翻译项目的实验验证。目标不是建设通用机器翻译工具，而是面向汽车标准法规文本，验证多语种法规翻译、术语约束、质量评估、速度并发和上层接口集成所需的关键能力。

翻译模块需要重点保证：

- 法规语义准确，避免漏译、误译和新增源文不存在的信息。
- 法规表达严谨，正确处理 shall、must、may、should 等义务程度。
- 汽车标准法规术语使用指定译法，并可统计术语一致率。
- 数字、单位、日期、法规编号、条款号和引用标准保持一致。
- 文档结构、章节、条款、列表和表格在可控范围内保留。
- 支持后续接入任务队列、结果回调、质量报告和上层应用。

## 2. 需求范围

当前模块覆盖以下能力：

1. 文本级翻译：支持单条或多条法规条款翻译。
2. 文档级翻译：支持对 PDF、DOCX、HTML、TXT、Markdown 等文档解析后翻译。
3. 多语种翻译：覆盖项目要求的重点语种方向。
4. 术语库约束：支持术语召回、Prompt 注入、译后校验和错误回流。
5. 质量评估：支持 XCOMET-QE、XCOMET-DA/COMET、TCR、数字一致率、格式保持率和人工复核。
6. 性能并发：以 250 字/秒和 10 文档并发为工程目标进行实验设计。
7. 接口集成：为任务提交、状态查询、结果获取和回调确认保留接口设计口径。

当前模块不直接负责标准法规文案生成、培训 PPT 生成、企业标准编写、图文检索、文文检索和多轮对话助手，但翻译结果需要能作为这些上层模块的输入。

## 3. 语种范围

必做语种方向：

| 语种方向 | 业务定位 | 自动评分目标 | DA 目标 |
|---|---|---:|---:|
| 英文到中文 | 核心语种 | XCOMET-QE >= 0.90 | >= 90/100 |
| 中文到英文 | 中英互译 | 建议 XCOMET-QE >= 0.90 | 建议 >= 90/100 |
| 西班牙语到中文 | 重点小语种 | XCOMET-QE >= 0.85 | >= 85/100 |
| 俄语到中文 | 重点小语种 | XCOMET-QE >= 0.85 | >= 85/100 |
| 德语到中文 | 主流出海市场语种 | XCOMET-QE >= 0.80 | >= 80/100 |
| 法语到中文 | 主流出海市场语种 | XCOMET-QE >= 0.80 | >= 80/100 |
| 泰语到中文 | 长尾语种 | XCOMET-QE >= 0.70 | >= 70/100 |
| 阿拉伯语到中文 | 长尾语种 | XCOMET-QE >= 0.70 | >= 70/100 |

待确认范围：马来语、印尼语。若后续纳入正式验收，需要补充数据、术语、评测和人工复核计划。

## 4. 核心验收目标

| 类别 | 目标 |
|---|---|
| 翻译质量 | XCOMET-QE 与 DA 按语种阈值同时达标，高风险样本进入人工复核。 |
| 术语一致性 | 术语库指定译法一致率 TCR >= 95%；当前实验阶段优先冲刺硬 TCR >= 90%。 |
| 数字一致性 | 数字、单位、日期、法规编号、标准号不得被误改。 |
| 格式保持 | 条款编号、列表、表格、章节结构尽量保留，复杂排版不要求 100% 还原。 |
| 性能 | 标准法规文档翻译速度目标不低于 250 原文字符/秒。 |
| 并发 | 支持同时处理 10 个文档级翻译任务。 |
| 接口 | 支持任务提交、状态查询、结果获取、回调确认和错误码。 |

## 5. 工程边界

首阶段以可复现实验闭环为主，不把训练、GRPO、完整生产系统、复杂文档排版还原作为前置条件。若训练数据或时间不足，应优先使用 Prompt 约束、术语后处理、多模型候选、候选重排和人工抽检闭环作为工程兜底。
