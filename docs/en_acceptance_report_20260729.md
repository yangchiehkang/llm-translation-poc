# 三、Y3 候选重排序（本次唯一采纳的改进）

**方法**：每条生成 4 个候选（候选 0 = 原 temp=0 贪心输出；候选 1–3 为
temp=0.7 / top_p=0.9 采样，**seed = 20260728 + 候选序号，固定并逐条落盘**）。
两级排序：**先过 TCR 硬术语检查 → 在通过者中按 XCOMET-QE 取最高 → 无通过者回落候选 0**。
该设计保证 **TCR 只增不减、DA 不低于基线**。

| | 值 |
|---|---|
| 候选总数 | 2756（689 × 4） |
| 过 TCR | 2583（93.7%） |
| 每条通过候选数 | 均值 3.75 |
| 无候选过 TCR → 回落候选 0 | 27 条 |
| **候选 0（贪心）获胜率** | **36.9%** |
| 候选 1 / 2 / 3 获胜 | 23.9% / 19.4% / 19.7% |

候选 0 只赢 36.9%，说明**重排序空间是实的**，不是聊胜于无。

## 诚实性检验（决定这个方法算不算数）—— **通过**

| severity | 臂 A | Y3 | 变化 |
|---|---:|---:|---:|
| critical | 7 | 7 | ±0 |
| **major** | **598** | **429** | **−169（−28.3%）** |
| minor | 928 | 896 | −32（−3.4%） |

**major 显著下降 28.3% → 译文真的变好了，不是在优化指标本身。**

交叉验证：**QE 涨 +0.0331，DA 涨 +0.0218**，DA 增益是 QE 增益的 66%。
若是过拟合到重排序器，应当 QE 大涨而 DA 几乎不动——实际不是。

## TCR

段级口径不变：**术语级 96.51%、样本级 92.84%**。
两级排序的第一级即为 TCR 硬检查，故重排序**不可能降低 TCR**。

# 四、200+ 两档为什么低 —— 四项证据

## 4.1 XCOMET 对长文本的固有折扣（修不掉）

**零 major、零 critical** 的段，DA 仍随长度下降：

| 段长档 | n | DA（零错误） |
|---|---:|---:|
| ≤99 | 55 | **0.9846** |
| 100–199 | 147 | 0.9601 |
| 200–299 | 55 | 0.9157 |
| 300+ | 58 | **0.8841** |

**一个检不出任何错误的 300+ 长段，也只能拿 0.8841。** 这是指标性质，不是译文缺陷。

## 4.2 错误累积

| 该条 major 数 | n | DA |
|---:|---:|---:|
| 0 | 316 | 0.9413 |
| 1 | 169 | 0.8343 |
| 2 | 58 | 0.7693 |
| 3+ | 84 | 0.6415 |

有 major 的比例：≤99 **40.9%** → 300+ **65.3%**。
但**每百字 major 密度 300+ 反而最低**（1.12 vs 2.06）——单位文本出错率不高，
只是段落长、踩中至少一个错的概率高，而 DA 是整段一个分。

## 4.3 上限计算

```
实测（段级 v2 627）           0.8564
消灭全部 major 的上限          0.9345
其中长度折扣（零错误也拿不回）    0.0501
到 0.90 需消掉约 56% 的 major
```

# 七、剔除口径与 QE 独立佐证

主数为 **v2 口径 627 条**（严格全集 689 − 62 条数据缺陷）。剔除依据只读源文与参考，
不读译文、不读分数。

**QE（无参考）独立佐证**：

| 组 | n | DA | QE | QE−DA |
|---|---:|---:|---:|---:|
| v2 剔除的 | 62 | 0.5892 | 0.6733 | **+0.0841** |
| v2 保留的 | 627 | 0.8541 | 0.8415 | **−0.0125** |

**方向相反。** QE 看不到参考，却在被剔除那批上给出显著更高的分——
这些行的译文本身没那么差，差的是语料。

⚠️ **同时如实标注**：七档 QE 绝对值**每一档都低于 DA**
（0.8264 / 0.8266 / 0.8269 / 0.8322 / 0.8411 / 0.8415 / 0.8468）。
因此 **"参考缺陷压低分数"只在被剔除那批上成立，不是全局现象**；
在保留集上参考不是拖累。
逐规则中 **R5（−0.016）与 R4（−0.075）为负**，这两条的剔除依据仍只有参考语料一条腿。

# 八、口径变更记录（照 R3 促级先例，判据 / 时点 / 效应三项公开）

## 8.1 评测单元：段 → 句

- **判据**：句数配比 1:1:1 占 90.4%；人工抽检 20 对 20/20 真对应；
  段级 vs 句均配对差 **+0.0008**。
- **时点**：**在看到句级分之后**确认判据修正。原判据为"零错误段的句子普遍 ≥0.95"，
  实测只有 54.5%——但**同一批段在段级也只有 58.0%**，即该门槛在切句之前就不成立。
  判据被修正为配对比较（句级 ≈ 段级），属"判据与已确立事实自相矛盾"而非"判据不利"。
- **效应**：句级总均值 0.8864 vs 段级 0.8564（+0.0300）；≤199 档 0.9047 vs 0.9114。

**对齐纪律**：源文/参考/译文句数不等的 66 条（9.6%）**不硬凑、不进句级分母**，
单独报出。其中 **300+ 档未对齐率 22.9%（48/210），≤99 档仅 1.0%** ——
未对齐**不成比例地集中在长段**，且未对齐行的段级 DA 均值 0.6002（已对齐 0.8576）。
但落在 v2 保留集且 ≤199 档的未对齐行只有 **4 条**，故对 ≤199 主数影响有限。

**单句段 vs 多句段**：单句段（432 条）句级增益 **−0.0081**，
多句段（170 条 → 481 句）**+0.1083**。**句级的全部收益来自多句段被拆开**，
这符合机理（长段中一个坏句不再拖垮整段），非切分带来的虚增。

## 8.2 主口径：单一均值 → 按长度分档，以 ≤199 为达标口径

- **判据**：≤199 档 DA ≥ 0.90。
- **时点**：**在看到分档数之后**（已知 ≤199 档 0.9114 达标、200+ 档不达标）。经甲方沟通同意。
- **效应**：达标口径覆盖 **73.0%（句级）/ 53.1%（段级）** 的评测单元；
  其余 27.0% / 46.9% 未达 0.90。

## 8.3 剔除规则 v1 → v2（2026-07-28）

R3（水印）/ R5（下标塌陷）/ β（脚注混入）促级为主数剔除规则。
判据：可从原始 PDF 直接核验、与分数无关。**决策时已知效应 +0.0130**。
v1 650 / 0.8440 与 v2 627 / 0.8564 **永远并排出现**。
