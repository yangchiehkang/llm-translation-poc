# LLM Translation POC

本项目是标准法规翻译子模块的实验仓库，主要用于验证汽车标准法规文本的多语种翻译、术语约束翻译和自动质量评估流程。

仓库目前主要服务于以下工作：

- 准备多语种法规评测样本；
- 调用翻译模型生成中文译文；
- 对普通翻译和术语约束翻译进行对比；
- 使用 XCOMET-XXL-QE 对译文质量进行评分；
- 检查术语库指定译法是否被正确使用；
- 整理低分样本和实验报告。

## 根目录结构

```text
llm-translation-poc/
├── configs/
├── data/
├── docs/
├── logs/
├── notes/
├── outputs/
├── scripts/
├── termbase/
├── README.md
└── .gitignore
```

## 根目录说明

| 目录 / 文件 | 说明 |
|---|---|
| `configs/` | 存放项目配置文件，例如语种、翻译模型、评估模型等配置 |
| `data/` | 存放实验数据，包括评测样本、翻译结果、评分结果和分析报告 |
| `docs/` | 存放项目文档，例如 Prompt、技术说明和实验说明 |
| `logs/` | 存放脚本运行日志 |
| `notes/` | 存放日报、周报、实验记录和问题记录 |
| `outputs/` | 存放临时输出文件 |
| `scripts/` | 存放项目脚本，包括数据处理、翻译、评分和术语检查脚本 |
| `termbase/` | 存放汽车标准法规术语库 |
| `README.md` | 项目说明文件 |
| `.gitignore` | Git 忽略文件配置 |

## 基本流程

项目的基本实验流程如下：

```text
1. 准备评测样本
   ↓
2. 调用翻译模型生成中文译文
   ↓
3. 使用术语库进行术语约束翻译
   ↓
4. 使用 XCOMET-XXL-QE 对译文进行质量评分
   ↓
5. 对比普通翻译和术语约束翻译结果
   ↓
6. 分析低分样本和术语一致性问题
```

## 数据流说明

评测样本一般放在：

```text
data/eval/
```

普通翻译结果一般放在：

```text
data/mt/qwen-max/
```

术语约束翻译结果一般放在：

```text
data/mt/qwen-max-term/
```

评分和分析报告一般放在：

```text
data/report/
```

术语库文件一般放在：

```text
termbase/
```

## 脚本说明

项目脚本主要放在 `scripts/` 目录下：

| 目录 | 说明 |
|---|---|
| `scripts/preprocess/` | 数据预处理脚本，例如分句、清洗、对齐等 |
| `scripts/mt/` | 翻译脚本 |
| `scripts/evaluation/` | 质量评分和结果分析脚本 |
| `scripts/termbase/` | 术语库加载、术语匹配和术语一致性检查脚本 |
| `scripts/utils/` | 通用工具脚本 |

## 说明

本仓库主要用于标准法规翻译实验验证，不是最终生产系统。当前重点是把翻译、术语约束、自动评分和结果分析流程跑通，并沉淀可复用的数据、脚本和报告。
